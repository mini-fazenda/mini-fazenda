# Recompensas de nível — controle do proprietário

O jogador vê duas opções e escolhe **uma**, recebendo também o bônus garantido. As probabilidades não aparecem na interface. A segunda opção é sorteada entre os itens restantes: nunca repete a primeira.

## Bônus garantido

| Níveis | Moedas |
|---|---:|
| 2–5 | 100 |
| 6–10 | 300 |
| 11–15 | 500 |
| 16–20 | 700 |
| 21–25 | 900 |

Depois, +200 moedas por faixa de cinco níveis. O bônus substitui o antigo crédito automático de nível; é entregue junto da escolha, uma única vez.
